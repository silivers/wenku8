## Wenku8Adapter 重写（修正实际页面结构不匹配问题）

### 问题背景
上一轮会话中发现原适配器与 wenku8 实际页面结构严重不匹配（HTTPS 不通、XPath 错误、URL 路径错误、列表页需登录），但修正工作被中断。

### 页面结构验证（3 轮 HTTP 请求验证）
- **协议**：HTTP 可用，HTTPS 不通（`http://www.wenku8.net`）
- **编码**：GBK
- **小说详情页**：`http://www.wenku8.net/book/{id}.htm`
  - 标题在 `<title>` 标签，格式 `标题 - 作者 - 文库 - 轻小说文库`
  - 详情在 table td 中，按行 "标签：值" 格式（小说作者/文章状态/文库分类/最后更新/全文长度/作品Tags/内容简介）
  - 封面 URL 规律：`http://img.wenku8.com/image/{id//1000}/{id}/{id}s.jpg`
- **章节目录**：`http://www.wenku8.net/novel/0/{id}/index.htm`
  - `table[@class="css"]//tr`，卷标题 `td[@class="vcss"]`，章节链接 `td//a[@href]`
  - 章节链接为相对路径（如 `2.htm`），用 `urljoin(index_url, href)` 拼接
- **章节正文**：`http://www.wenku8.net/novel/0/{id}/{chapter_href}`
  - 标题在 `div#title`，正文在 `div#content`
  - 多页格式：`{chapter_id}_{page}.htm`（不是 `{chapter_id+1}.htm`）
  - "下一页"链接同时用于翻页和跳下一章，必须检查 href 含 `_` 才是同章分页
  - 插图 CDN：`https://pic.777743.xyz/`
- **全站列表**：`articlelist.php`/`toplist.php`/`search.php` 全部需登录
  - 改用 ID 递增遍历（1~5000），跳过 404 和错误页
