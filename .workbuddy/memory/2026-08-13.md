## 轻小说爬虫框架实现

- 根据 `wenku8/design_v3.md`（v3.1）用 Python 实现完整框架
- 项目结构：`novel/` 包，含 core/engine/middlewares/pipelines/storage/exporters/adapters/http/utils/cli 模块
- 核心实现：
  - 核心抽象层：BaseAdapter、ConfigAdapter、中间件基类（Request/Response）、Pipeline 基类、StorageBackend 抽象
  - 引擎：CrawlerEngine（asyncio + Semaphore 并发 + RateLimiter 限速）+ TaskManager（断点续爬）
  - 中间件：UserAgent（轮换）、RateLimit（域名级）、Retry（指数退避）、Encoding（三级检测）、ContentVerify（蜜罐/字数校验）
  - 管道：HTMLCleaner（lxml 清洗）、TextNormalizer（归一化）、Deduplication（SHA-256 去重）、QualityValidator（乱码/截断/蜜罐检测，记日志不阻断）
  - 存储：SQLiteBackend（aiosqlite，自动迁移，WAL 模式）
  - 导出：EPUBExporter（ebooklib，保留排版标准，卷封面/插图/后记支持）
  - 适配器：Wenku8Adapter（GBK 编码 + 多页合并）+ ConfigAdapter（YAML 配置驱动）+ AdapterRegistry（目录扫描自动加载）
  - CLI：click 框架，支持 sites/search/crawl/update/export/list/info/stats/delete/tasks/config 命令
- 依赖：httpx, lxml, aiosqlite, ebooklib, Pillow, charset-normalizer, click, loguru, PyYAML
- 验证：全部导入通过、CLI 命令正常、SQLite CRUD 测试通过、EPUB 导出测试通过、管道测试通过、编码检测测试通过
- 修复 aiosqlite 事件循环关闭报错问题（手动管理 event loop + shutdown_asyncgens）
